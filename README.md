# 💰 Argent Bank

Une application bancaire front-end développée avec **React** et **TypeScript**.  
Elle permet aux utilisateurs de se connecter, consulter leurs comptes, et gérer leurs transactions de manière simple et sécurisée.

---

## 🚀 Fonctionnalités

- Authentification sécurisée (connexion / déconnexion)
- Affichage des informations utilisateurs
- Consultation des comptes bancaires
- Détails et historique des transactions
- Responsive design

---

## 🛠️ Technologies utilisées

- [React](https://reactjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [React Router](https://reactrouter.com/)
- [Redux Toolkit](https://redux-toolkit.js.org/) 
- [Vite](https://vitejs.dev/)
